# UUID Studio

UUID Studio is a focused, browser-based UUID (Version 4) generator built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Lucide React, and the `uuid` package. The app generates one secure UUID at a time, lets users copy it from a polished card UI, and explains common UUID use cases directly on the landing page.

## Project Overview

This repository contains a single-page Next.js application that runs as an App Router project. The primary user flow is intentionally simple:

1. Open the generator page.
2. View the UUID that is created when the client component initializes.
3. Click the UUID card to copy the current value.
4. Click **Generate** to replace it with a new Version 4 UUID.
5. Read the built-in UUID overview and usage examples below the generator.

The interface does not store generated UUIDs in local storage, cookies, a database, or server state. Generated values live only in the current page state until the page is refreshed or a new UUID is generated.

## Features

- 🔐 **Secure UUID v4 generation**: Uses the browser `crypto.randomUUID()` API when available and falls back to `uuid` package `v4()` generation.
- 📋 **One-click copy**: Clicking the UUID card copies the current UUID through the Clipboard API, with a textarea fallback for older browser support.
- ✅ **Copy feedback states**: Shows a temporary copied state and an animated error message if copying fails.
- 🔄 **Regenerate action**: Replaces the current UUID with a new Version 4 value and resets copy status.
- 🧠 **Built-in education**: Includes a short explanation of UUIDs, common use cases, and practical JavaScript, SQL, and API examples.
- 🎨 **Responsive glass UI**: Uses Tailwind CSS utility classes for gradients, glassmorphism, responsive layout, light/dark color schemes, and accessible focus styling.
- ✨ **Animated interactions**: Uses Framer Motion for entrance animations, button interaction states, and copy-error transitions.
- 🧩 **Icon system**: Uses Lucide React icons for navigation, feature badges, action buttons, and documentation cards.

## Application Architecture

### UUID generation

`src/app/page.tsx` defines a `createUuid()` helper. It first checks for `crypto.randomUUID()` in the browser runtime and uses it when present. If the API is unavailable, it calls `uuidv4()` from the `uuid` package.

### Copy behavior

The `copyText()` helper attempts to use `navigator.clipboard.writeText()`. When the Clipboard API is unavailable, it creates a hidden textarea, selects the UUID text, runs `document.execCommand('copy')`, and removes the textarea.

### State management

The generator is a client component and keeps only two pieces of React state:

- `uuid`: the currently displayed UUID.
- `copyStatus`: an `idle`, `copied`, or `failed` status used to render copy feedback.

There is no backend API, database, generated-history list, or persisted browser storage.

### Styling and layout

Global styling lives in `src/app/globals.css`, which imports Tailwind CSS, defines font theme tokens, sets light/dark background variables, enables smooth scrolling, and applies base element styles. Most visual styling is composed directly in `src/app/page.tsx` with Tailwind utility classes.

### Metadata

`src/app/layout.tsx` exports page metadata for the application title and description. It also configures light and dark `themeColor` values through Next.js viewport metadata.

## Getting Started

### Prerequisites

- Node.js compatible with the installed Next.js version.
- npm, which is used by the included `package-lock.json`.

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

1. Load the home page.
2. Copy the initial UUID by clicking the dark UUID card or the copy affordance inside it.
3. Click **Generate** to create a new UUID v4 value.
4. Use the documentation cards as quick examples for pasting UUIDs into JavaScript, database schema definitions, or API payloads.

## Notes for Future Development

Potential enhancements that fit the current architecture include:

- Downloading generated values as text or JSON.
